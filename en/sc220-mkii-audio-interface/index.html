PRODUCT IDENTITY

Three products that should not be confused.

SC220 MKII is an audio-interface hardware product. SC220 Live is a Windows mixing application. KTV Pro K500 is a separate karaoke processor.

HARDWARE

Recording Tech SC220 MKII

A two-channel USB audio interface for microphones, line sources, instruments, monitoring, and computer capture.

WINDOWS SOFTWARE

SC220 Live

Combines SC220 input with PC audio, ASK-P Signature processing, metering, ducking, and broadcast routing.

KARAOKE PROCESSOR

KTV Pro K500

Processes microphones, music, and karaoke effects before or outside the computer capture stage.

Compatibility must not be assumed. This page documents the SC220 MKII hardware. SC220 Live support for the MKII remains unconfirmed until a physical unit is tested and its Windows input/output names are documented.

CONNECTION DIAGRAMS

Six practical signal paths.

Begin with low levels. Set hardware input gain while watching the meter, then adjust monitor and software levels separately.

DYNAMIC MIC

Dynamic microphone

Connect by XLR, leave +48 V off, use mic mode, and raise gain gradually.

Dynamic mic → XLR → SC220 MKII → USB → Windows
CONDENSER MIC

Condenser microphone

Lower gain, connect by XLR, enable +48 V only when required, then raise gain.

Condenser mic → XLR → +48 V → SC220 MKII
INSTRUMENT

Guitar or bass

Use a 6.35 mm cable and select Instrument/INST for an appropriate high-impedance input.

Guitar / bass → INST → SC220 MKII → DAW
LINE SOURCE

Karaoke processor or mixer

Use Line mode. Engage PAD if the source remains too hot even with low input gain.

Processor L/R → LINE 1/2 → PAD if needed → SC220 MKII
LIVE STREAM

SC220 Live into OBS

Use this path only after the MKII appears as a stable Windows endpoint and application compatibility is confirmed.

SC220 MKII → SC220 Live → VB-CABLE → OBS / TikTok Live
DIRECT MONITOR

Monitoring without echo

When direct monitoring is active, disable duplicate software monitoring to avoid doubled audio.

Input → Direct monitor → Headphones / monitor speakers

OPERATION

A safe sequence from silence to a clean signal.

Input gain, application fader, monitor volume, and headphone volume are different controls and should be treated separately.

01 — HARDWARE

Prepare the connection

  1. Lower gain and monitor volume.
  2. Connect the correct source.
  3. Select Line or Instrument as required.
  4. Enable +48 V only when necessary.
02 — WINDOWS

Confirm device detection

  1. Use a data-capable USB cable.
  2. Check Windows Sound and Device Manager.
  3. Match sample rates between applications.
  4. Record the exact endpoint names.
03 — GAIN

Set level at the source

  1. Speak or play at real performance level.
  2. Raise gain without reaching clipping.
  3. Use PAD for excessively hot line sources.
  4. Then adjust software faders.
04 — OBS

Select the correct input

  1. Add Audio Input Capture.
  2. Select the SC220 MKII endpoint.
  3. Use mono for a single microphone when needed.
  4. Make a test recording before streaming.
05 — SC220 LIVE

Validate before GO LIVE

  1. Select the detected hardware input.
  2. Select PC Audio and Stream Output.
  3. Check meters and left/right mapping.
  4. Confirm there is no echo or clipping.
06 — MOBILE

OTG is not guaranteed universally

  1. Use a suitable data cable or adapter.
  2. Check the power requirement.
  3. Test applications individually.
  4. Do not promise universal phone support.

TROUBLESHOOTING

Answers to the most common search questions.

Start at the hardware and Windows layers before changing DSP or application faders.

The SC220 MKII does not appear in Windows.

Use a data-capable USB cable, try another USB port without a hub, restart the interface, and check Windows Sound and Device Manager. Record the hardware ID if it appears as an unknown device.

Does it need a dedicated driver or ASIO?

No verifiable official driver page has been found. Do not install drivers from random websites. First document the device name and formats exposed by Windows.

Why is a microphone only on the left channel?

A single microphone is mono on one input. Select the matching mono channel or enable mono in OBS or the DAW.

A condenser microphone produces no signal.

Confirm that an XLR cable is used, the microphone requires phantom power, +48 V is enabled, gain is sufficient, and the cable is working. Lower gain before switching phantom power.

When should the −20 dB PAD be used?

Use it when a mixer, karaoke processor, or other source still clips with low input gain. PAD does not replace correct gain staging.

What is the difference between Line and Instrument?

Line is for processors, mixers, and line-level outputs. Instrument/INST is for guitar or bass pickups requiring a high-impedance input.

Why do I hear echo or doubled audio?

Direct monitoring and software monitoring may be active together. Choose one monitoring path or stop the application from returning the input a second time.

Why does it clip even after lowering the OBS fader?

The preamp may clip before audio reaches the computer. Lower hardware input gain or engage PAD first; an OBS fader cannot repair an already distorted analogue signal.

Does the SC220 MKII have hardware loopback?

It is unverified. Do not depend on loopback until the actual endpoints and routing are tested. SC220 Live uses software routing to endpoints such as VB-CABLE.

Can it be used directly with Android?

OTG is claimed in public product information, but phone compatibility, power, adapters, and application support have not been tested.

Does SC220 Live support the SC220 MKII?

Not yet confirmed. Minimum validation should record endpoint names, channel mapping, sample rates, capture stability, monitoring output, and reconnect behaviour.
