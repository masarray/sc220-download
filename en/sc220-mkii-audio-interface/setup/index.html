SC220 MKII SETUP GUIDE

Set up the SC220 MKII for what you actually want to do.

Start with the correct signal path instead of turning up every knob. This guide separates hardware gain, monitoring, the SC220 Live mix, and the final OBS level so clipping, weak signal, echo, or one-sided audio can be diagnosed faster.

COMPATIBILITY STATUS

Test hardware and software separately.

Do not assume every device sold as SC220 has the same driver, channel map, sample rates, loopback, or Windows endpoint names. SC220 Live compatibility with the MKII still requires a physical-unit test.

Gain staging: fix level at the earliest stage.

A software fader cannot repair an analog input that is already clipping. The monitor knob is not input gain.

1

Source

Microphone, guitar, mixer, or karaoke processor. Know the source type and approximate level.

2

Input mode

Select mic, line, or instrument. Enable +48 V only when required. Use PAD when a line source remains too strong.

3

Hardware gain

Start low, raise it while watching the meter, and leave room for the loudest moment.

4

Software mix

Set faders, mute, ducking, or DSP only after the hardware signal is clean and stable.

5

Broadcast

Use OBS or destination faders for final adjustment, then make a short test recording.

Diagnostic order: disable DSP and duplicate monitoring, test one source, check the input meter, check the mix meter, then check OBS. Do not raise several stages at once.

Connection routes by use case.

Button names and endpoint labels may vary by revision. Match the chassis label and the name that actually appears in Windows.

VOCAL RECORDING

Dynamic or condenser microphone

  1. Lower gain and monitor level.
  2. Connect the microphone through XLR.
  3. For a condenser that requires phantom power, enable +48 V after connecting the cable.
  4. Select a mono input so the vocal does not appear only on one side.
  5. Raise gain while performing the loudest section, then record a test.
MIC → XLR INPUT → HARDWARE GAIN → DAW / SC220 LIVE
LIVE STREAMING

OBS or TikTok Live Studio

  1. Confirm the SC220 is visible and its input meter moves.
  2. Select it as the source in SC220 Live or the capture application.
  3. When using SC220 Live, select the correct stream output.
  4. Choose the matching receiving endpoint in OBS or TikTok.
  5. Avoid capturing the same source twice.
SC220 → SC220 LIVE → STREAM OUTPUT → OBS / TIKTOK
TWO-MIC PODCAST

Two microphones, two gain controls

  1. Connect the first microphone to input 1 and the second to input 2.
  2. Set gain separately for each speaker.
  3. Confirm the application maps both channels as intended.
  4. Use headphones to check noise, bleed, and level differences.
  5. Do not enable phantom power without checking each microphone requirement.
MIC 1 → INPUT 1 + MIC 2 → INPUT 2 → APP
GUITAR / BASS

Instrument mode

  1. Connect the instrument with a 6.35 mm cable.
  2. Select instrument mode when available on that input.
  3. Start with low gain and play the loudest section.
  4. Choose direct monitoring or software monitoring, not both.
  5. Add amp simulation after the input is clean.
GUITAR / BASS → INST INPUT → GAIN → APP
KARAOKE PROCESSOR

Treat it as a line source

  1. Connect processor L/R outputs to two inputs for stereo.
  2. Select line mode, not instrument mode.
  3. Start with low processor output and interface gain.
  4. Use PAD if the level remains too strong.
  5. Check for stacked processing that causes pumping or distortion.
PROCESSOR L/R → LINE INPUT 1/2 → SC220 LIVE → OBS
USB OTG

Phone or tablet

  1. Use a data-capable cable or adapter, not charge-only.
  2. Check whether the mobile device can provide enough power.
  3. Select the SC220 in the audio application when available.
  4. Test input, output, monitoring, and long-session behavior.
  5. Use a powered hub only when needed and appropriate for the devices.
SC220 USB-C → OTG ADAPTER → MOBILE APP

BEFORE OPENING AN ISSUE

Provide evidence so support does not have to guess.

A model photo, Windows device name, input mode, sample rate, wiring, meter screenshot, and reproduction steps are more useful than “there is no sound”.
