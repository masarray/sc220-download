WINDOWS INSTALLATION

From installer to a stream-ready audio route.

  1. Download the SC220 Live installer from the official button above.
  2. Run the installer as Administrator.
  3. Follow the automatic prerequisite checks.
  4. Install Standard VB-Audio VB-CABLE only when your streaming route requires it.
  5. Open SC220 Live and select the correct Recording Tech SC220 input and Windows playback source.
  6. Select CABLE Input as Stream Output when using VB-CABLE.
  7. In OBS or TikTok Live Studio select CABLE Output as the audio source.
  8. Make a test recording before going live and check the meters for clipping.
SC220 DOWNLOAD FAQ

Questions people ask before downloading.

Where is the official SC220 Live download?

Use this page or GitHub Releases at masarray/sc220-download. Public releases include a SHA-256 checksum and manifest for verification.

Is SC220 Live free to download?

Yes. The installer can be downloaded without a credit card. Full creative control is available for 365 days; core audio functions continue after that period.

Is this a Recording Tech SC220 driver?

No. SC220 Live is a Windows mixer and audio console; a hardware driver, if required, is a separate component.

Do I have to use VB-CABLE?

Not always. VB-CABLE is a common virtual route for sending the final mix to broadcasting software.
