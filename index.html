PERTANYAAN UMUM

Jawaban singkat.

Apakah SC220 Live software karaoke?

SC220 Live adalah mixer dan audio console untuk live streaming. Aplikasi ini tidak mengelola katalog lagu atau menampilkan lirik karaoke.

Apakah SC220 Live software kontrol KTV Pro K500?

Tidak. KTV K500 adalah karaoke processor terpisah. Baca panduan KTV K500 untuk memahami pembagian fungsinya.

Apakah harus memakai OBS?

Tidak. Aplikasi Windows lain yang menerima endpoint audio dapat digunakan.

Apa fungsi VB-CABLE?

VB-CABLE membawa hasil mix dari SC220 Live menuju aplikasi siaran.
