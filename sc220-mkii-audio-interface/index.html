KENALI PRODUKNYA

Tiga nama yang sering tercampur.

SC220 MKII adalah hardware audio interface. SC220 Live adalah aplikasi mixer Windows. KTV Pro K500 adalah karaoke processor terpisah.

HARDWARE

Recording Tech SC220 MKII

Audio interface USB dua kanal untuk microphone, line source, instrumen, monitoring dan koneksi komputer.

WINDOWS SOFTWARE

SC220 Live

Menggabungkan input SC220 dan audio PC, menerapkan ASK-P Signature, metering, ducking dan routing ke aplikasi siaran.

KARAOKE PROCESSOR

KTV Pro K500

Memproses microphone, musik dan efek karaoke sebelum atau di luar tahap capture komputer.

Kompatibilitas belum boleh diasumsikan. Halaman ini membahas hardware SC220 MKII. SC220 Live belum dinyatakan kompatibel dengan MKII sampai unit diuji langsung dan nama input/output Windows terdokumentasi.

CARA PAKAI

Urutan aman dari nol sampai terdengar.

Pisahkan input gain, fader aplikasi, volume monitor dan volume headphone. Keempatnya memiliki fungsi berbeda.

01 — HARDWARE

Siapkan koneksi

  1. Turunkan gain dan volume monitor.
  2. Hubungkan microphone atau source yang benar.
  3. Pilih Line/Instrument sesuai perangkat.
  4. Aktifkan +48 V hanya bila dibutuhkan.
02 — WINDOWS

Pastikan device muncul

  1. Gunakan kabel USB yang mendukung data.
  2. Periksa Windows Sound dan Device Manager.
  3. Samakan sample rate antar aplikasi.
  4. Catat nama input dan output persis.
03 — GAIN

Atur level dari sumber

  1. Bicara atau mainkan instrumen pada level nyata.
  2. Naikkan gain sampai kuat namun tidak clipping.
  3. Aktifkan PAD bila sumber line terlalu panas.
  4. Baru atur fader software.
04 — OBS

Pilih input yang benar

  1. Tambahkan Audio Input Capture.
  2. Pilih endpoint SC220 MKII.
  3. Untuk satu mic, gunakan mono bila perlu.
  4. Rekam tes pendek sebelum live.
05 — SC220 LIVE

Validasi sebelum GO LIVE

  1. Pilih input hardware yang terdeteksi.
  2. Pilih PC Audio dan Stream Output.
  3. Periksa meter dan kanal kiri/kanan.
  4. Konfirmasi tidak ada echo atau clipping.
06 — MOBILE

OTG belum pasti universal

  1. Gunakan adapter/kabel data yang sesuai.
  2. Periksa kebutuhan daya perangkat.
  3. Uji aplikasi satu per satu.
  4. Jangan menjanjikan semua ponsel kompatibel.

TROUBLESHOOTING

Jawaban untuk masalah yang paling sering dicari.

Mulai dari hardware dan Windows sebelum mengubah DSP atau fader aplikasi.

SC220 MKII tidak muncul di Windows. Apa yang harus dicek?

Gunakan kabel USB yang mendukung data, coba port USB lain tanpa hub, nyalakan ulang perangkat, lalu periksa Windows Sound dan Device Manager. Catat hardware ID bila perangkat muncul sebagai unknown device.

Apakah perlu driver khusus atau ASIO?

Belum ditemukan halaman driver resmi yang dapat diverifikasi. Jangan menginstal driver dari situs acak. Dokumentasikan dahulu nama device dan format yang tersedia di Windows.

Mengapa microphone hanya terdengar di kiri?

Satu microphone adalah sumber mono pada satu input. Pilih kanal mono yang sesuai atau aktifkan opsi mono pada OBS/DAW agar suara berada di tengah.

Condenser microphone tidak bersuara.

Pastikan menggunakan kabel XLR, microphone memang memerlukan phantom power, +48 V aktif, input gain cukup, dan kabel tidak rusak. Turunkan gain sebelum mengaktifkan atau mematikan phantom power.

Kapan memakai PAD −20 dB?

Gunakan saat output mixer, karaoke processor atau sumber lain tetap clipping walaupun input gain sudah rendah. PAD bukan pengganti gain staging yang benar.

Apa beda Line dan Instrument?

Line digunakan untuk output processor, mixer atau perangkat berlevel line. Instrument/INST digunakan untuk gitar atau bass pasif yang membutuhkan input impedansi tinggi.

Mengapa terdengar echo atau suara dobel?

Biasanya direct monitoring dan software monitoring aktif bersamaan. Pilih salah satu jalur monitoring atau atur software agar input tidak dipantulkan dua kali.

Mengapa masih clipping walau fader OBS sudah diturunkan?

Clipping dapat terjadi di preamp sebelum audio masuk komputer. Turunkan input gain hardware atau gunakan PAD terlebih dahulu; fader OBS tidak dapat memperbaiki sinyal analog yang sudah terdistorsi.

Apakah SC220 MKII memiliki hardware loopback?

Belum terverifikasi. Jangan mengandalkan loopback sampai endpoint dan routing aktual diuji. SC220 Live menyediakan jalur software menuju aplikasi siaran melalui endpoint seperti VB-CABLE.

Apakah dapat digunakan langsung di Android?

OTG diklaim pada informasi produk publik, tetapi kompatibilitas ponsel, kebutuhan daya, adapter dan aplikasi belum diuji. Gunakan klaim ini secara hati-hati.

Apakah SC220 Live mendukung SC220 MKII?

Belum dipastikan. Pengujian minimum harus mencatat nama endpoint, channel mapping, sample rate, kestabilan capture, output monitoring dan perilaku setelah reconnect.
