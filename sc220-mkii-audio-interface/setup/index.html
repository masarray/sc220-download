SC220 MKII SETUP GUIDE

Cara setting SC220 MKII berdasarkan tujuan Anda.

Mulai dari jalur sinyal yang benar, bukan dari menaikkan semua knob. Panduan ini memisahkan gain hardware, monitoring, mix SC220 Live, dan level akhir di OBS agar masalah clipping, suara kecil, echo, atau kanal kiri dapat ditemukan lebih cepat.

Pilih kebutuhan sayaBuka checklist support
STATUS KOMPATIBILITAS

Hardware dan software harus diuji terpisah.

Jangan menganggap semua unit yang bernama SC220 memiliki driver, channel map, sample rate, loopback, atau endpoint Windows yang sama. Kompatibilitas SC220 Live dengan MKII tetap harus dikonfirmasi menggunakan unit fisik.

Saya ingin menggunakan SC220 MKII untuk…

Pilih tujuan terdekat. Setiap jalur dimulai dari sumber, mode input, gain hardware, monitoring, kemudian software.

01 · MICROPHONE

Merekam vocal

Dynamic atau condenser microphone, phantom power, mono input, dan level rekaman.

 02 · STREAMING

OBS / TikTok Live

Capture input, SC220 Live, VB-CABLE, monitoring, dan tes sebelum live.

 03 · DUA ORANG

Podcast dua microphone

Input 1 dan 2, gain terpisah, monitoring, dan pengaturan kanal.

 04 · INSTRUMENT

Gitar atau bass

Input jack, mode instrument, level pickup, dan monitoring tanpa echo.

 05 · LINE SOURCE

Karaoke processor

Output L/R processor, line input, PAD bila diperlukan, dan gain netral.

 06 · USB OTG

Smartphone / tablet

Kabel, daya, aplikasi, dan batas kompatibilitas yang wajib diuji.

Gain staging: perbaiki level dari tahap paling awal.

Fader software tidak dapat memperbaiki input analog yang sudah clipping. Monitor knob juga bukan input gain.

1

Sumber

Microphone, gitar, mixer, atau karaoke processor. Pastikan jenis dan level sumber diketahui.

2

Mode input

Pilih mic, line, atau instrument. Aktifkan +48 V hanya bila microphone memang memerlukannya. Gunakan PAD ketika sumber line terlalu kuat.

3

Gain hardware

Mulai rendah, naikkan sambil memantau meter, dan sisakan ruang aman untuk bagian paling keras.

4

Mix software

Atur fader, mute, ducking, atau DSP setelah sinyal hardware bersih dan stabil.

5

Broadcast

Gunakan fader OBS atau aplikasi tujuan sebagai penyesuaian akhir, kemudian rekam tes pendek.

Urutan diagnosis: matikan DSP dan monitoring ganda, uji satu sumber, cek meter input, cek meter mix, lalu cek meter OBS. Jangan menaikkan beberapa tahap sekaligus.

Rute pemasangan berdasarkan penggunaan.

Nama tombol dan endpoint dapat berbeda antar revisi. Cocokkan dengan label unit dan nama yang benar-benar muncul di Windows.

VOCAL RECORDING

Dynamic atau condenser microphone

  1. Turunkan gain dan monitor level.
  2. Hubungkan microphone melalui XLR.
  3. Untuk condenser yang membutuhkan phantom, aktifkan +48 V setelah kabel terpasang.
  4. Pilih input mono di aplikasi agar vocal tidak hanya muncul di kiri atau kanan.
  5. Naikkan gain sambil menyanyikan bagian paling keras, lalu rekam tes.
MIC → XLR INPUT → HARDWARE GAIN → DAW / SC220 LIVE
LIVE STREAMING

OBS atau TikTok Live Studio

  1. Pastikan SC220 terlihat dan meter input bergerak.
  2. Pilih SC220 sebagai sumber di SC220 Live atau aplikasi capture.
  3. Jika memakai SC220 Live, pilih stream output yang benar.
  4. Di OBS/TikTok, pilih endpoint penerima yang sesuai.
  5. Hindari menangkap sumber yang sama dua kali.
SC220 → SC220 LIVE → STREAM OUTPUT → OBS / TIKTOK
TWO-MIC PODCAST

Dua microphone, dua gain

  1. Hubungkan microphone pertama ke input 1 dan kedua ke input 2.
  2. Atur gain tiap pembicara secara terpisah.
  3. Pastikan aplikasi membaca kedua kanal sesuai kebutuhan mono/stereo.
  4. Gunakan headphone untuk memeriksa noise, bleed, dan perbedaan volume.
  5. Jangan menyalakan phantom untuk seluruh jalur tanpa memeriksa kebutuhan microphone.
MIC 1 → INPUT 1 + MIC 2 → INPUT 2 → APP
GUITAR / BASS

Mode instrument

  1. Hubungkan instrumen menggunakan jack 6,35 mm.
  2. Pilih mode instrument bila tersedia pada input tersebut.
  3. Mulai gain rendah dan mainkan bagian paling keras.
  4. Pilih direct monitor atau software monitor, bukan keduanya sekaligus.
  5. Tambahkan amp simulation setelah sinyal bersih.
GUITAR / BASS → INST INPUT → GAIN → APP
KARAOKE PROCESSOR

Masuk sebagai line source

  1. Hubungkan output L/R processor ke dua input untuk stereo.
  2. Pilih line mode, bukan instrument.
  3. Mulai output processor dan gain interface dari rendah.
  4. Gunakan PAD bila level tetap terlalu kuat.
  5. Pastikan tidak ada processing ganda yang menyebabkan pumping atau distorsi.
PROCESSOR L/R → LINE INPUT 1/2 → SC220 LIVE → OBS
USB OTG

Smartphone atau tablet

  1. Gunakan kabel atau adapter data, bukan kabel charge-only.
  2. Periksa apakah perangkat mobile dapat memberi daya yang cukup.
  3. Pilih SC220 di aplikasi audio bila tersedia.
  4. Uji input, output, monitoring, dan durasi penggunaan.
  5. Gunakan powered hub hanya bila dibutuhkan dan sesuai spesifikasi perangkat.
SC220 USB-C → OTG ADAPTER → MOBILE APP
